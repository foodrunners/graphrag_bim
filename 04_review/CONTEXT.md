# Compare clauses with project evidence

## Inputs

Use the question, the relevant output from [03 GraphRAG](../03_graphrag/CONTEXT.md), the cited pages in `../01_source/output/code.pdf` and the project's drawings, schedules or model measurements. A geometry check takes a measured quantity, its unit, its measurement basis and the relevant object or space.

## Process

Copy the [review template](../_templates/review.md) to `output/` using the project or issue identifier as the filename. Identify the trigger, the requirement and the evidence needed to evaluate it. Compare each in-scope requirement separately and distinguish verified measurements from open evidence.

## Outputs

One dated review per question. The [worked example](example.md) uses synthetic project evidence.

For a review spanning agencies, record the trigger, clause, source and evidence for each obligation in its own row. See the [multi-code cases and expansion guide](multicode.md).

## Check

A reviewer verifies each requirement against the specified edition, clause and page. A finding of conformity on a specific test requires the corresponding project evidence. Mark missing evidence as open.
