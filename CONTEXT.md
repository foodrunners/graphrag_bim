# From Code edition to review finding

The unit of work is a design question for a stated building use, location and submission date. The source edition is shared across questions. Each project review records its own evidence.

| Stage | Handoff |
|---|---|
| [01 Source](01_source/CONTEXT.md) | Verified PDF and fingerprint |
| [02 Evidence](02_evidence/CONTEXT.md) | Searchable records with source pages |
| [03 GraphRAG](03_graphrag/CONTEXT.md) | Candidate references and connected source records |
| [04 Review](04_review/CONTEXT.md) | Source-checked finding and outstanding evidence |

The BCA full scope uses one record per page. Its pilot uses selected clauses and supporting records. The multi-code scope indexes individually sourced summaries from three documents and expands retrieval through [reviewed links](02_evidence/links.csv). Reviewers open the source locators and apply the project facts before recording a finding.
